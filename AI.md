1. Sobre o projeto

O AlertaJá é um projeto desenvolvido para a Global Solution do 2º semestre de Engenharia de Software da FIAP.
A proposta é criar uma plataforma que ajude moradores a se prepararem para situações de risco causadas por chuvas fortes, enchentes e alagamentos.
A plataforma busca reunir informações importantes em um só lugar, permitindo que os usuários acompanhem áreas de risco, consultem alertas meteorológicos, registrem ocorrências e encontrem informações sobre abrigos e rotas alternativas.
A região piloto definida pelo grupo foi Itaquaquecetuba, em São Paulo.

2. Ferramentas de Inteligência Artificial utilizadas

Durante o desenvolvimento do projeto, foram utilizadas ferramentas de IA como apoio em diferentes etapas:
* ChatGPT: utilizado para esclarecer dúvidas, estudar conceitos de programação, discutir ideias, organizar funcionalidades e auxiliar no planejamento do projeto.
* VS Code AI: utilizado como apoio durante o desenvolvimento, principalmente para analisar a estrutura existente do projeto, identificar problemas no código, sugerir soluções e auxiliar na implementação de funcionalidades.

3. Como a IA foi utilizada

As ferramentas foram utilizadas para auxiliar em questões relacionadas ao desenvolvimento do AlertaJá, como:

* Organização das ideias e funcionalidades da plataforma.
* Discussão sobre a melhor forma de estruturar o projeto.
* Esclarecimento de dúvidas sobre React, JavaScript e Tailwind CSS.
* Estudo sobre integração com APIs e comunicação entre front-end e back-end.
* Discussão sobre autenticação de usuários e operações CRUD.
* Identificação de possíveis erros e alternativas para solucioná-los.
* Planejamento da integração com serviços meteorológicos e mapas.

4. Tecnologias envolvidas

Durante o planejamento e desenvolvimento, foram utilizadas ou consideradas as seguintes tecnologias:

* React
* Vite
* JavaScript
* Tailwind CSS
* Node.js
* Express
* SQLite
* APIs externas

As tecnologias foram escolhidas considerando as necessidades do projeto e a integração entre suas funcionalidades.

5. Funcionalidades do projeto

O AlertaJá foi planejado para oferecer:

* Mapa com visualização de áreas e ocorrências de risco.
* Alertas relacionados às condições meteorológicas.
* Cadastro de relatos de alagamentos pelos moradores.
* Confirmação e contestação de ocorrências.
* Consulta de abrigos e pontos de apoio.
* Sugestão de rotas alternativas.
* Cadastro e autenticação de usuários.

As funcionalidades estão sendo desenvolvidas e verificadas ao longo do projeto.

6. Participação e responsabilidade da equipe

A Inteligência Artificial foi utilizada como ferramenta de apoio, mas as decisões relacionadas à proposta, às funcionalidades e à organização do projeto são de responsabilidade da equipe.
Os integrantes devem compreender as soluções utilizadas, acompanhar o desenvolvimento, verificar os resultados e realizar os testes necessários.
As sugestões fornecidas pelas ferramentas são analisadas de acordo com as necessidades do AlertaJá, não sendo consideradas automaticamente corretas.

7. Considerações finais

O uso de ferramentas de Inteligência Artificial contribuiu como apoio durante o desenvolvimento do AlertaJá, principalmente para facilitar o entendimento de conceitos, explorar soluções e auxiliar na identificação de problemas técnicos.
A equipe continua responsável pelo desenvolvimento, pela validação das funcionalidades e pelo resultado final do projeto.
